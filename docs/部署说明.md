# 部署说明（Netlify）

本网站为纯静态站点，无后端、无数据库、无构建步骤，所有数据保存在访问者浏览器本地。

## 目录结构

```
异人内网13/
├── index.html        主页面（页面结构）
├── sw.js             Service Worker（通知点击、离线）
├── netlify.toml      Netlify 配置
├── assets/
│   ├── logo.png      哪都通 logo
│   ├── css/
│   │   └── main.css  全部样式（由原内联样式合并）
│   └── js/
│       └── app.js    全部交互逻辑（由原内联脚本提取）
└── docs/
    ├── 使用指南.md
    ├── 部署说明.md
    └── screenshots/  页面截图
```

## 方式一：拖拽部署（最简单）

1. 打开 <https://app.netlify.com/drop>（需登录 Netlify，可免费注册）。
2. 把整个 `nadutong-final` 文件夹**直接拖进网页**。
3. 等待几秒即得到一个 `https://xxx.netlify.app` 链接，完成。

> 注意：拖入的是包含 `index.html` 的整个文件夹，不要只拖一个文件。

## 方式二：连接 Git 仓库

1. 把文件夹推送到 GitHub / GitLab 仓库。
2. Netlify 里「Add new site → Import an existing project」。
3. 构建命令留空，Publish directory 填 `.`（根目录）。
4. 部署即可。

## 更新网站

- 拖拽方式：在站点「Deploys」里重新拖入新文件夹。
- Git 方式：push 后 Netlify 自动重新部署。

## 数据与隐私说明

- 所有账号、帖子、聊天、档案均存在**访问者自己的浏览器**（IndexedDB，兼容 localStorage），不同人、不同设备的数据互不相通。
- 因此每个人看到的内容都可以不一样，非常适合各自做 cosplay 与对话体创作。
- 想把自己的数据分享给别人，在「数据中心」导出 JSON，对方导入即可。

## 自定义域名（可选）

在 Netlify 站点「Domain settings」里添加自己的域名，按提示解析 DNS 即可，Netlify 会自动签发 HTTPS 证书。

## 本地预览

直接双击 `index.html` 即可在浏览器打开；如个别浏览器对本地文件有限制，可在该目录下运行一个简单静态服务，例如：

```
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

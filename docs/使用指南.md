# 哪都通 · 使用指南

一个明面是普通快递官网、暗面是异人论坛的双面网站。所有数据只保存在你当前浏览器里（本地存储，无后端、无服务器），可直接部署到 Netlify 等静态平台。

---

## 一、明面（普通快递网站）

打开网页看到的是「哪都通快递」官网：

- **查快递**：输入运单号查询物流轨迹。内置示例单号 `NDT7770001234`、`NDT6660005678`；输入其他单号会自动生成一条物流记录。
- **网点查询**：按华北、华东、华南、华中、西南、西北、东北 **七大区** 查看网点。
- **寄件 / 新闻 / 关于**：常规快递页面。

## 二、进入暗面（异人论坛）

两种方式：

1. 页面**最底部**有一个极小的「员工入口」；
2. 在首页**连续点击左上角 logo 5 次**。

进入后先**注册账号**（无需真实信息），再登录。

### 权限分级（严格）

| 身份 | 等级 | 能看到什么 |
| --- | --- | --- |
| 普通异人 | 1 | 论坛、聊天室、私信、好友、抽签、个人空间 |
| 哪都通员工 | 2 | 额外开放异人档案、事件档案、资料库、专属名片、工作组、OA |
| 管理员 | 3 | 全部内容，含绝密档案，并可审批、删帖 |

- 无权限的条目，名称一律显示为 `****`，有权限后才显示真实文字。
- 身份激活码（在「数据中心」输入）：
  - 员工：`NDT-EMP`
  - 管理员：`NDT-MGR`
  - 恢复普通异人：`NDT-USER`

---

## 三、异人论坛（知乎式）

- **发帖 / 回答**：可发长文、加表情、插图片。
- **板块**：公告、异人讨论、功法交流等，板块可自行新增、改名、删除（管理员）。
- **赞同 / 浏览数**：可正常点赞；点「编辑」可直接**修改发帖人姓名、回答人姓名、浏览数、赞同数、正文**，方便做论坛体。
- 管理员可**删帖 / 删回答**。

## 四、聊天室（群聊）

- 最多可建 **3 个独立聊天室**，顶部标签切换，「＋新建」开新房间；每个房间的成员、消息、字卡配置**互不影响**，房间可改名。
- 「成员管理」勾选要加入的人；「TA 发言 ▾」下拉，或直接点某个成员头像，TA 就会发一条「请输入内容」。
- 我自己发的消息显示我的头像和名字。
- **每条消息都能改、能删**；点气泡编辑，或**长按消息**弹出「引用 / 撤回 / 删除」。

## 五、私信（一对一）

- 在「私信」里选择用户发起聊天。
- 点对方头像或「+ TA 回复一条」，对方回一条「请输入内容」；点几下回几条。
- 我方消息显示我方头像；可发照片。
- 点气泡编辑，长按消息可「引用 / 撤回 / 删除」。

### 创作模式 / 字卡模式

私信和聊天室顶部都能切换：

- **创作模式**：默认，手动控制每条消息。
- **字卡模式**：你发一条消息后，系统会从对方的「字卡」里随机抽 **1～5 条**自动连发（含组合回复）。
  - **回复速度**：秒回（8 秒内）、自然（60 秒内）、深思熟虑（3 分钟内）。
  - **字卡管理**：给某个人添加字卡，单人上限 **999 条**。
    - 文字 / 表情算文字卡；图片单独成卡（图片是图片）。
    - 支持**组合回复**（一条字卡连发多条）。
    - **批量添加**：一行一个字卡，重复内容自动跳过。
    - **导入**：支持 txt（一行一个）或 json（含图片）；**导出**可仅导文字（txt）或导出全部（json，含图片）。
  - **主动**：勾选后进入字卡会话时对方会主动发一条；可关闭。
  - 创作模式下只保留模式切换入口，不显示字卡配置。

> 自动回复依赖页面保持打开（浏览器定时器），关闭页面后不会再回复。

## 六、红包 / 转账（模拟）

私信、聊天室、工作组、字卡模式下都能发，点输入框的 **🧧** 按钮选择红包或转账，金额自填。

- 红包有「福」字信封，点开会显示已领取金额；转账显示 ¥ 金额。
- **字卡模式**下对方有概率主动发红包 / 转账，金额随机、偏大额，但不超过 **1 亿**，且带千分位逗号，不会出现超长数字。
- 纯模拟，不产生真实交易。

## 七、抽签问吉

侧栏「抽签问吉」，道教风格，每日一签：大吉 / 中吉 / 小吉 / 平 / 小凶 / 凶，附签诗与解读。**每天只能问一次**，次日重置。

## 八、工作组（员工 / 管理员）

员工及以上可见的内部群，功能同聊天室：成员管理、TA 发言、红包、消息可改可删。

## 九、OA 办公（员工 / 管理员）

- 可填报**任务表**、提交**请假申请**。
  - 任务表字段详尽：任务名称、类型（巡查/调查/抓捕/护送/潜伏/后勤等）、优先级（普通/紧急/特急）、起止时间、地点、任务目标、执行计划、所需资源、风险评估、预期成果。
- 管理员在「全部审批」里可**批准 / 驳回 / 删除**；驳回可填意见。

## 十、异人档案 · 关系树

打开任意异人档案，下方有「关系树」：可添加该人物与他人的关系（如师父、敌人、同事），带备注，可删除。

- 关系可标**方向**：单向（→）或**双向（⇄）**。选双向时，若对方也在异人档案中，会自动在对方档案里写入反向关系。

## 十一、内网主题美化

内网顶栏可切换三套整体主题，选择会本地保存：

- **默认**：深蓝公务风。
- **日间**：浅底深字，明亮清爽。
- **夜间**：近黑底，暗光护眼。

## 十二、个人空间 / 装修

- 每个人的空间可自由装修，提供深蓝公务、橙意速运、暗夜终端、青玉道家、朱砂镇邪、宣纸水墨等模板。
- 可改昵称、头像、简介、留言。

## 十三、数据中心

- 查看本地数据占用；**导出 JSON** 备份或分享，在其他浏览器 / 设备**导入**。
- 可重置为初始数据。
- 存储优先使用浏览器的 IndexedDB（容量较大，可存较多图片），并自动兼容 localStorage。

---

**小提示**：图片会自动压缩；如果存了大量图片导致空间紧张，可在数据中心导出备份后清理。转发网站时请连同 `assets` 文件夹一起发送。
